creating and loading a VM using qemu

* Create qcow2

qemu-img create -f <qcow2 name-of-vm>.qcow2 <size>G

* install ISO

=qemu-system-x86_64= -enable-kvm -m 4096 -cpu host -smp 2 -hda =debian_vm.qcow2= -cdrom =/path/to/iso -boot d 
-vga std

* launch VM

=qemu-system-x86_64= -enable-kvm -m 4096 -cpu host -smp 2 -hda =debian_vm.qcow2= -vga std
